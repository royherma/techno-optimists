# Stack

Picked 2026-09-10. Every row was read off a neighbouring project on disk or live vendor
docs, not from memory. Sources cited per row.

## The stack

```
FRONTEND   Astro 7 (static) + React islands + Tailwind v4 (@tailwindcss/vite)
              | fetch /api/*
API        Hono + Zod v4 on Workers  |  Better Auth (D1)
              |- D1        challenges, people, typed actions
              |- D1 #2     analytics ONLY (split from day one)
              |- R2        media, zero egress
              |- images    native image transforms
              |- media     Media Transformations (video downscale, beta/unbilled)
              |- KV        hot feed cache
              +- Vectorize similarity graph [P3 - DEFER, triggers $5 plan]
REALTIME   Durable Objects (SQLite) + WebSocket hibernation
ASYNC      Queues + Workflows (ingest is multi-step and fails midway)
AI         Workers AI: transcribe / translate / tag
           Anthropic API: the structuring pass (rambling video -> Challenge)
```

Mental model: Astro serves the feed fast, Hono handles the API, D1/R2/KV hold the data,
Durable Objects run the live layer, Queues/Workflows absorb ingest, AI turns media into a
Challenge page.

## Three deliberate departures from creators-of-today

1. **No polymorphic `resources` + `resource_types` registry.** That is COT's scar from
   retrofitting six kinds into one table. We have ONE object with four entry types - that is a
   `type` column on `challenges`, not a registry.
2. **One typed-actions table from the start.** `challenge_actions(user_id, challenge_id, kind)`
   where kind is one of the seven social actions. COT splits `likes`/`ratings`/`saves` into
   three tables doing one job.
3. **Analytics D1 split on day one.** COT bolted on `cot-analytics` only after real overload
   incidents (`creators-of-today/wrangler.jsonc:106-113`).

## Cost at MVP

$5/mo Workers Paid. R2 egress $0, Media Transformations unbilled in beta, Vectorize deferred.
Video is the only line that can surprise us - that is exactly why R2 + Media Transformations
beats Stream until retention numbers exist.

Cloudflare Stream, for the record, is $5/mo per 1,000 minutes stored plus $1 per 1,000 minutes
delivered (https://developers.cloudflare.com/stream/pricing/, read 2026-09-10). Revisit only
when the feed proves people watch.

## Traps already paid for next door

- Node 22 + nvm does not persist across shell calls. Prefix wrangler/astro commands:
  `export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 22 >/dev/null`. Symptom is a
  silent no-op. (COT GOTCHAS #1)
- HTML comments are invalid inside Astro JSX expressions - use `{/* */}`. (COT GOTCHAS #6)
- A spend cap must gate on the vendor's real ledger, never a locally-inferred price, or it
  fails open. (COT GOTCHAS #10h)
